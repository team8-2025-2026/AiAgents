# Решение проблемы "Не удалось создать чат"

## Возможные причины:

### 1. Пользователь не авторизован или не имеет статус STUDENT

**Решение:**
- Убедитесь, что вы вошли в систему
- Проверьте, что ваш пользователь имеет статус `STUDENT`
- Если вы создали пользователя со статусом `ASSISTENT`, создайте нового со статусом `STUDENT`

### 2. Chat API не может найти пользователя

**Проблема:** Chat API использует ту же базу данных, что и Auth API, но не может найти пользователя по `access_token`.

**Решение:**
1. Убедитесь, что Chat API использует правильную базу данных:
   - Проверьте файл `chatapi/.env`:
     ```
     CONNECTION_STRING=sqlite:///../authapi/database.db
     ```
2. Перезапустите Chat API после изменения `.env` файла

### 3. Chat API не запущен или не отвечает

**Решение:**
1. Проверьте, что Chat API запущен на порту 8001:
   ```powershell
   netstat -ano | findstr :8001
   ```
2. Откройте в браузере: http://localhost:8001/docs
3. Если не работает, перезапустите:
   ```powershell
   cd chatapi
   python -m uvicorn main:app --reload --port 8001
   ```

### 4. Проблема с CORS

**Решение:** Я уже добавил CORS middleware в Chat API. Перезапустите Chat API.

### 5. Access token не передается

**Решение:**
1. Откройте консоль браузера (F12)
2. Перейдите на вкладку **Application** → **Local Storage** → `http://localhost:3000`
3. Проверьте, что есть ключ `access_token` с каким-то значением
4. Если токена нет, выйдите и войдите заново

## Пошаговая диагностика:

1. **Откройте консоль браузера (F12)**
2. **Перейдите на вкладку Network**
3. **Попробуйте создать чат**
4. **Найдите запрос к `/chat`**
5. **Посмотрите:**
   - URL запроса (должен быть `http://localhost:8001/chat?access_token=...`)
   - Статус ответа (200, 400, 401, 500?)
   - Тело ответа (что вернул сервер?)

## Создание пользователя со статусом STUDENT:

1. Откройте http://localhost:8000/docs
2. Найдите **PUT /user**
3. Заполните:
   - `email`: ваш email
   - `first_name`: ваше имя
   - `last_name`: ваша фамилия
   - `status`: **STUDENT** (важно!)
   - `access_token`: `secret_admin_token_12345`
4. Сохраните пароль из ответа
5. Войдите в WebUI с этим email и паролем

## Проверка работы Chat API:

Проверьте вручную через браузер:
```
http://localhost:8001/docs
```

Найдите эндпоинт **PUT /chat** и попробуйте создать чат с вашим `access_token`.
