# Как открыть консоль разработчика в браузере

## Chrome / Edge (Chromium)

### Способ 1: Горячие клавиши
- **Windows/Linux**: `F12` или `Ctrl + Shift + I`
- **Mac**: `Cmd + Option + I`

### Способ 2: Через меню
1. Нажмите на три точки (⋮) в правом верхнем углу
2. Выберите **"Дополнительные инструменты"** → **"Инструменты разработчика"**

### Способ 3: Правой кнопкой мыши
1. Кликните правой кнопкой мыши на странице
2. Выберите **"Просмотреть код"** или **"Inspect"**

## Firefox

### Способ 1: Горячие клавиши
- **Windows/Linux**: `F12` или `Ctrl + Shift + I`
- **Mac**: `Cmd + Option + I`

### Способ 2: Через меню
1. Нажмите на три линии (☰) в правом верхнем углу
2. Выберите **"Дополнительные инструменты"** → **"Инструменты веб-разработки"**

## Safari

1. Включите меню разработчика:
   - Safari → Настройки → Дополнения
   - Поставьте галочку "Показывать меню разработчика"
2. Затем используйте `Cmd + Option + I`

## Что делать после открытия консоли

1. **Вкладка Console** - здесь будут ошибки JavaScript
2. **Вкладка Network** - здесь видно, какие файлы загружаются
3. **Вкладка Elements** - здесь виден HTML код страницы

## Если консоль не открывается

Попробуйте:
- Обновить страницу (`F5`)
- Закрыть и открыть браузер заново
- Попробовать другой браузер (Chrome, Firefox, Edge)
