# API для работы с заявками учителя

## Описание

Когда нейросеть определяет, что вопрос ученика требует ответа учителя, она создает заявку на подключение учителя. Учитель может просматривать список заявок и принимать их, создавая новый чат с учеником.

## Модель данных

### TeacherRequest

```python
{
    "id": int,                    # ID заявки
    "chat_id": int,               # ID исходного чата с нейросетью
    "student_id": int,             # ID ученика
    "question_message_id": int,    # ID сообщения, после которого нейросеть позвала учителя
    "status": str,                # PENDING, ACCEPTED, REJECTED
    "teacher_id": int | null,     # ID учителя, который принял заявку
    "created_at": float           # Время создания заявки (timestamp)
}
```

### Chat (обновлено)

Добавлено поле:
- `needs_teacher: bool` - флаг, что нейросеть запросила учителя

## API Endpoints

### GET `/teacher_requests`

Получить список заявок на подключение учителя.

**Параметры:**
- `access_token` (query) - токен доступа учителя/ассистента

**Ответ:**
```json
{
    "success": true,
    "data": [
        {
            "id": 1,
            "chat_id": 5,
            "student": {
                "id": 2,
                "first_name": "Иван",
                "last_name": "Иванов",
                "status": "STUDENT",
                "description": ""
            },
            "teacher": null,
            "question_message_id": 10,
            "question_text": "Как решить это уравнение?",
            "status": "PENDING",
            "created_at": 1234567890.123
        }
    ]
}
```

**Ошибки:**
- `"Пользователь не найден"` - неверный access_token
- `"Только учитель или ассистент могут просматривать заявки"` - пользователь не является учителем/ассистентом

### POST `/teacher_requests/{request_id}/accept`

Принять заявку на подключение учителя и создать новый чат.

**Параметры:**
- `request_id` (path) - ID заявки
- `access_token` (query) - токен доступа учителя/ассистента

**Ответ:**
```json
{
    "success": true,
    "data": {
        "id": 6,
        "student_title": "Чат с учителем (из чата #5)",
        "assistent_title": "Чат с Иван Иванов",
        "student": {
            "id": 2,
            "first_name": "Иван",
            "last_name": "Иванов",
            "status": "STUDENT",
            "description": ""
        },
        "assistent": {
            "type": "HUMAN",
            "data": {
                "id": 3,
                "first_name": "Петр",
                "last_name": "Петров",
                "status": "TEACHER",
                "description": ""
            }
        },
        "needs_teacher": false
    }
}
```

**Ошибки:**
- `"Пользователь не найден"` - неверный access_token
- `"Только учитель или ассистент могут принимать заявки"` - пользователь не является учителем/ассистентом
- `"Заявка не найдена"` - неверный request_id
- `"Заявка уже обработана"` - заявка уже принята или отклонена
- `"Исходный чат не найден"` - исходный чат был удален
- `"Ученик не найден"` - ученик был удален

## Логика работы

### Создание заявки

1. Ученик отправляет сообщение в чат с нейросетью
2. Нейросеть анализирует вопрос
3. Если нейросеть определяет, что нужен учитель, она:
   - Добавляет маркер `[NEEDS_TEACHER]` в конец ответа
   - Создает заявку `TeacherRequest` со статусом `PENDING`
   - Устанавливает `needs_teacher = True` в чате
   - Отправляет сообщение ученику: "Ваш вопрос передан учителю. Ожидайте ответа."
   - Перестает отвечать в этом чате

### Принятие заявки

1. Учитель просматривает список заявок через `GET /teacher_requests`
2. Учитель выбирает заявку и нажимает "Принять"
3. Система:
   - Создает новый чат между учеником и учителем
   - Копирует всю историю сообщений из исходного чата до момента вызова учителя
   - Добавляет системное сообщение: "Учитель {имя} подключился к чату."
   - Обновляет статус заявки на `ACCEPTED`
   - Учитель может начать общаться с учеником в новом чате

### Для ученика

- Исходный чат с нейросетью остается без изменений
- В чате отображается сообщение о том, что вопрос передан учителю
- Нейросеть больше не отвечает в этом чате
- Когда учитель принимает заявку, создается отдельный новый чат

## Примеры использования

### Получить список заявок

```bash
curl "http://localhost:8001/teacher_requests?access_token=YOUR_TOKEN"
```

### Принять заявку

```bash
curl -X POST "http://localhost:8001/teacher_requests/1/accept?access_token=YOUR_TOKEN"
```

## Интеграция с фронтендом

### Для учителя

1. Создать страницу/компонент для отображения списка заявок
2. При клике на заявку - показать детали (вопрос ученика, история чата)
3. Кнопка "Принять заявку" вызывает `POST /teacher_requests/{id}/accept`
4. После принятия - перенаправить в новый созданный чат

### Для ученика

1. В чате с нейросетью отображать статус `needs_teacher`
2. Показывать сообщение "Ваш вопрос передан учителю. Ожидайте ответа."
3. Отключить возможность отправки сообщений в чат, где `needs_teacher = True` (опционально)
