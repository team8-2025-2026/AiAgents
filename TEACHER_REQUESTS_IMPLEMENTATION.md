# Реализация системы заявок для подключения учителя

## Что было реализовано

### 1. Модели данных

- **TeacherRequest** - модель для хранения заявок на подключение учителя
  - `id` - ID заявки
  - `chat_id` - ID исходного чата с нейросетью
  - `student_id` - ID ученика
  - `question_message_id` - ID сообщения, после которого нейросеть позвала учителя
  - `status` - статус заявки (PENDING, ACCEPTED, REJECTED)
  - `teacher_id` - ID учителя, который принял заявку
  - `created_at` - время создания заявки

- **Chat** (обновлено)
  - Добавлено поле `needs_teacher: bool` - флаг, что нейросеть запросила учителя

### 2. Логика работы нейросети

- Нейросеть анализирует вопросы ученика
- Если вопрос требует экспертного мнения учителя, нейросеть:
  - Добавляет маркер `[NEEDS_TEACHER]` в конец ответа
  - Создает заявку `TeacherRequest` со статусом `PENDING`
  - Устанавливает `needs_teacher = True` в чате
  - Отправляет сообщение ученику: "Ваш вопрос передан учителю. Ожидайте ответа."
  - Перестает отвечать в этом чате

### 3. API Endpoints

#### GET `/teacher_requests`
- Получение списка заявок для учителя/ассистента
- Возвращает только заявки со статусом `PENDING`
- Сортировка по времени создания (новые первыми)

#### POST `/teacher_requests/{request_id}/accept`
- Принятие заявки учителем
- Создает новый чат между учеником и учителем
- Копирует историю сообщений из исходного чата до момента вызова учителя
- Добавляет системное сообщение о подключении учителя
- Обновляет статус заявки на `ACCEPTED`

### 4. Поведение для пользователей

#### Для ученика:
- Исходный чат с нейросетью остается без изменений
- В чате отображается сообщение о том, что вопрос передан учителю
- Нейросеть больше не отвечает в этом чате (`needs_teacher = True`)
- Когда учитель принимает заявку, создается отдельный новый чат

#### Для учителя:
- Видит список заявок в отдельном разделе
- Может просмотреть детали заявки (вопрос ученика)
- При принятии заявки создается новый чат с полной историей до момента вызова учителя
- Может сразу начать общаться с учеником

## Как использовать

### Для разработчиков

1. Убедитесь, что база данных обновлена (SQLModel автоматически создаст новые таблицы)
2. Нейросеть автоматически будет определять необходимость учителя при ответах
3. Учитель может просматривать заявки через `GET /teacher_requests`
4. Учитель принимает заявку через `POST /teacher_requests/{id}/accept`
